TabDesk – installation v0.1.5

Debian / Kali / Ubuntu. Källkoden ligger på GitHub under MIT-licens.

Enklast – allt i ett

Hämtar nyckeln, kontrollerar fingeravtrycket innan den skrivs, installerar:

curl -fsSL https://cdn.thern.io/tabdesk/install.sh | sudo bash

Vill du granska skriptet först:

curl -fsSL https://cdn.thern.io/tabdesk/install.sh -o td.sh
less td.sh
sudo bash td.sh

Eller steg för steg

Kommandona är avsiktligt skrivna utan variabler. Raderna blir långa, men kopiera hela raden – en halvt inklistrad variabelrad ger annars en tom [signed-by=] och felet Malformed entry 1 in list file.

1) Hämta signeringsnyckeln till en temporär fil:

curl -fsSL https://cdn.thern.io/tabdesk/tabdesk-archive-keyring.gpg -o /tmp/td.gpg

2) Kontrollera att det verkligen är nyckeln – innan den skrivs:

gpg --show-keys /tmp/td.gpg

Ska visa B40E D009 54B3 B564 21F5  8C99 B9D4 4CBC 6F2B D93E och TabDesk APT repository <info@thern.io>. Står det något annat: sluta här, inget är skrivet än.

3) Lägg nyckeln på plats:

sudo install -m644 /tmp/td.gpg /usr/share/keyrings/tabdesk.gpg

4) Apt-källa (en enda rad):

echo "deb [signed-by=/usr/share/keyrings/tabdesk.gpg] https://cdn.thern.io/tabdesk stable main" | sudo tee /etc/apt/sources.list.d/tabdesk.list

5) Installera:

sudo apt update && sudo apt install tabdesk

Om något gick fel

Malformed entry 1 in list file … ([option] no value)
Källfilen innehåller [signed-by=] utan värde – steg 4 klistrades in ofullständigt. Kontrollera med cat /etc/apt/sources.list.d/tabdesk.list; raden ska innehålla hela sökvägen till nyckeln. Enklast är att låta skriptet skriva om filen:

curl -fsSL https://cdn.thern.io/tabdesk/install.sh | sudo bash

Parse-fel om nyckelringen från apt: då är /usr/share/keyrings/tabdesk.gpg inte en nyckel utan troligen en HTML-sida – ta bort filen och kör samma rad som ovan.

Underhåll

sudo apt update && sudo apt upgrade tabdesk   # uppdatera
sudo apt remove tabdesk                        # avinstallera

Om du fick instruktionerna via mejl

Skicka inte nyckeln direkt in i nyckelringen med en pipe. Mejlklienter skriver om länkar – Gmail gör om URL:en till www.google.com/url?q=…. En sådan länk svarar 200 med en HTML-sida, curl -f accepterar den, och HTML:en hamnar i nyckelringen. Enda symtomet blir ett parse-fel från apt som inte pekar på orsaken. Kontrollera nyckeln först, skriv den sedan. Ser en länk ut att gå till www.google.com i stället för cdn.thern.io – skriv adressen för hand.

Direkt .deb

tabdesk_0.1.5_amd64.deb

Tarball – utan apt

tabdesk-0.1.5.tar.gz

tar xzf tabdesk-0.1.5.tar.gz
./tabdesk-0.1.5/tabdesk

Tarbollen packar bara upp och kör – ingen apt-källa, alltså inga uppdateringar och inga beroenden installerade åt dig. Det här måste finnas sedan tidigare: xterm, xdotool, python3-gi, libgtk-3-0, libnss3, libxss1, libxtst6, libsecret-1-0, libnotify4. Startar appen inte, kör den från en terminal – ett saknat bibliotek syns i felraden.
